## Как пользоваться

- Навигация слева — разделы и регламенты.
- Поиск сверху — по ключевым словам, номерам документов и фразам из текста.
- Исходные `.docx`/`.rtf` преобразованы в удобный для чтения формат.

::: tip Быстрый старт
Ищите по номеру (например, `ИП 3`, `Регламент 24`) или по действию (`передача смены`, `маркировка деталей`, `клеймо качества`).
:::
