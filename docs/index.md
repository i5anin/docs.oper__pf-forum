# Главная

Цель документации — обеспечить единообразные правила работы: качество, безопасность, регламенты смен, логистика и обслуживание оборудования.

## Как пользоваться
- Навигация слева — разделы и регламенты.
- Поиск сверху — поиск по ключевым словам.
- Метка «Обновлено» вверху страницы — контроль актуальности информации.

## Структура
- **ЧАВО** — ответы на часто задаваемые вопросы.
- **Производство** — инструкции для операторов, мастеров, ОТК, склада и обслуживания.

## Ответственность
Каждый сотрудник обязан соблюдать регламенты.  
Все несоответствия фиксируются в информационной системе предприятия и подлежат разбору в рамках процедуры CAPA.
