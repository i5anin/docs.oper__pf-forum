# Главная

Цель документации — обеспечить единообразные правила работы на Заводе №5: качество, безопасность, регламенты смен, логистика и обслуживание оборудования.

## Как пользоваться
- Навигация слева — разделы и регламенты.
- Поиск сверху — ищите по ключевым словам.
- Метка «Обновлено» вверху страницы — контроль актуальности.

## Структура
- **ЧАВО** — ответы на частые вопросы.
- **Производство** — инструкции для операторов, мастеров, ОТК, склада и обслуживания.

## Ответственность
Каждый сотрудник соблюдает регламенты. Несоответствия фиксируются в ИС предприятия и разбираются по CAPA.
