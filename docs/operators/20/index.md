## 1. Введение

### 1.1. Назначение регламента

Настоящий регламент определяет порядок контроля и движения продукции, несоответствующей конструкторской документации (КД) или техническому процессу (ТП) и прошедшей проверку контролёром ОТК на операционном и приёмо-сдаточном контроле.

### 1.2. Область применения

Регламент распространяется на:

* директора по производству (ЗТВ),
* руководителей отделений №4, №5,
* начальников отделов №11А, №12А, №12Т, №12Ф, №13,
* технологов-программистов,
* мастеров смен токарной и фрезерной групп,
* мастера слесарного участка,
* наладчиков,
* операторов станков с ЧПУ,
* контролёров ОТК,
* слесарей слесарного участка,
* упаковщиков.

Каждый сотрудник, ответственный за элементы процесса, обязан выполнять требования данного регламента.

## 2. ⚙️ Описание процесса

### 2.1. Цель регламента

Систематизация правильного движения забракованной продукции в производстве ООО «ПФ-ФОРУМ».

### 2.2. Замысел

Строгое выполнение установленных регламентом действий каждым сотрудником, участвующим в процессе движения забракованной продукции.

### 2.3. Изготовление продукции

* Годные детали оператор станков с ЧПУ помещает в серую пластиковую тару с заполненным вкладышем: ФИО, дата, номер смены, наименование детали, номер операции, количество.
* При участии нескольких специалистов: **1 оператор → 1 серый ящик → 1 вкладыш**.

### 2.4. Отработка

* Отработка первой детали новой операции производится на заготовке из красного ящика (с биркой «Бланк брака»).
* Если детали нет — используется годная.
* После отработки:

    * если деталь годная → в общую партию,
    * если есть отклонения → в красный ящик с оформлением бирки.
* Красный ящик перемещается с партией по всем этапам.

### 2.5. Операционный контроль

* Для продукции ГОЗ оператор ЧПУ выполняет **100% контроль**.
* Для остальных партий — выборочный контроль:

| Партия   | Выборка          |
| -------- | ---------------- |
| 10 шт.   | проверить каждую |
| 30 шт.   | каждую 3-ю       |
| 50 шт.   | каждую 5-ю       |
| 100 шт.  | каждую 5-ю       |
| 500 шт.  | каждую 10-ю      |
| 1000 шт. | каждую 10-ю      |

* Если партия не проверена ОТК, оператор в синей футболке крепит бирку «❌ Не проверено ОТК».
* Контролёр ОТК:

    * делает 10% выборку,
    * ставит отметку в системе,
    * прикрепляет синюю бирку ✅ «Проверено ОТК».
* Убирать красные бирки может **только контролёр ОТК**.

### 2.6. Отклонения качества

* Дневная смена: оператор сообщает мастеру и приглашает ОТК.
* Ночная смена: решение принимает мастер.
* Действия оператора:

    * пересортировать,
    * несоответствующие детали — в красную тару с биркой «Бланк брака».
* Передача красных ящиков:

    * дневная смена — сразу контролёру,
    * ночная смена — утром контролёру.

### 2.7. Исправление отклонений

* Исправление: оператор или с привлечением специалистов.
* Если исправить нельзя:

    * ОТК использует бирки:

        * 🟡 Жёлтая — незначительные отклонения (требует согласования),
        * 🔴 Красная — окончательный брак.
* Контролёр фиксирует данные в журнале и системе, отправляет уведомления в Viber и Telegram.
* НО12Т/НО12Ф анализируют отклонения 2 раза в день.
* Если исправить нельзя — решение о согласовании принимает комиссия (НО12Т, НО12Ф, НО11А, заказчик).

### 2.8. Доработка

* Включается в план НО12Т/НО12Ф, выполняется за сутки.
* После доработки детали помещаются на место «ДЕТАЛИ ПОСЛЕ ДОРАБОТКИ» с жёлтой биркой.
* Если оператор ЧПУ доработал сам в течение 3 суток — брак снимается из его рейтинга.

### 2.9. Приёмо-сдаточный контроль

* Контролёр ОТК выполняет:

    * 100% визуальную проверку,
    * 10% выборку по КД.
* Годная партия → бирка зелёного цвета ✅.
* Если есть замечания:

    * 🟡 Жёлтая бирка — при отклонениях, требующих согласования,
    * 🔴 Красная — при окончательном браке.
* Решение о дальнейшем движении деталей принимает комиссия (НО11А, НО12А, НО13).

## 3. 📌 Ответственность за соблюдение регламента

* Правила регламента защищают интересы работников.
* За несоблюдение — дисциплинарная или административная ответственность.
* От скорости и правильности выполнения зависит выполнение заказа, объём производства и доход компании.

## 4. 📊 Контроль исполнения

* Ответственный: директор по производству.
* Контроль исполнения — МСИ на еженедельной основе.
