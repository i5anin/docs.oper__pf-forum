# Инструктивное письмо

## По правилам использования и хранения технологической оснастки на токарном участке производства компании ООО «ПФ-ФОРУМ»

Данное инструктивное письмо направлено на рациональный поиск и правильное использование технологической оснастки на токарном участке, а также на уменьшение количества простоев при наладке на токарных станках с ЧПУ.

---

## 📑 Перечень технологической оснастки на токарном участке

### 1. Шкаф для не твердосплавных свёрл

* Используется для хранения не твердосплавных свёрл диаметром от 1мм до 10.7мм.

### 2. «Штакетница» для свёрл с пластинами

* Содержит только сверла с пластинами.
* ❌ Без втулок!

### 3. Ящик с не твердосплавными сверлами диаметром от 10.8мм

* Содержит только не твердосплавные сверла диаметром от 10.8мм.
* Сверла с коническим хвостовиком хранятся на фрезерном участке.
* ⚠️ Запрещено помещать в данный ящик непригодный к использованию инструмент!

### 4. Капролоновые «Штакетницы», находящиеся на столе

* Используются под разнообразный цилиндрический инструмент.
* ✅ Необходимо строго сохранять порядок расположения:

    * метчики с метчиками,
    * микрорезцы не перемешивать с фрезами и т.д.

### 5. Стенд для хранения цанг

* Предназначен для хранения и быстрого поиска нужных цанг.
* Цанги ER40, ER8 хранятся на фрезерном участке.

### 6. Ящик под инструмент

* Используется для хранения инструмента, требующего докомплектации, ремонта или утилизации.

### 7. Ящик под использованные пластины

### 8. Ящик под сверла и фрезы, требующих заточки

### 9. Стеллаж под съёмные блоки

* Съёмные блоки после снятия со станков в обязательном порядке должны быть продуты от стружки и поставлены на стеллаж.

### 10. Инструментальный шкаф

* Используется для хранения металлорежущего инструмента.
* ⚠️ Инструмент, требующий докомплектации, ремонта или утилизации, **НЕ должен находиться в данном шкафу**.

### 11. Шкаф для переходных втулок

* Содержит переходные втулки для расточного инструмента, а также цанговые патроны.
* Все втулки должны быть разобраны (без инструмента).

### 12. Кассетница с комплектующими для станков

* Используется для хранения вспомогательной оснастки на станках токарного участка.
* Каждая ячейка подписана по названию и имеет свой нормативный запас.
* Для удобства поиска необходимой оснастки с левой стороны кассетницы прописан перечень всех ячеек.
* Для облегчения поиска нужной оснастки для станка все комплектующие после снятия должны убираться в свои ячейки.

---

## 🛠 Обязанности наладчика (ежемесячно)

1. Проверить запас комплектующих согласно списку Приложения №1.
2. Составить список необходимой оснастки, которую требуется закупить или изготовить на производстве компании ООО «ПФ-ФОРУМ».
3. Передать данный список начальнику производства НО 12А.
4. НО 12А включает в план производства оснастку, которую необходимо изготовить на станках с ЧПУ.

    * Начальник отдела подготовки производства делает заявку на закупку остальных комплектующих.
5. При изготовлении и поступлении комплектующих оснастку передают наладчику станков с ЧПУ.
6. Наладчик распределяет оснастку по ячейкам в кассетнице.
